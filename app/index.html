开机自动启动星契

登录 Windows 后在托盘静默待命，随时可召唤。

召唤动画时长

演出越慢越有仪式感，越快越利落。当前约 4.0 秒。

关闭窗口后驻留系统托盘

关掉大厅窗口不退出，托盘图标可随时回来、快速召唤或退出。

已召唤小窗方向

主界面最小化或退回托盘时浮出，列出已召唤的 Agent。竖向贴屏幕右侧，横向贴底部居中。

固定小窗位置

开启后小窗不能被拖动，切换应用时也保持原位；关闭时长按小窗任意位置即可拖动，松手自动吸附在屏幕内。

agent 配置

「选择」可从本机已装的程序里挑启动目标；「常驻」的 agent 会随星契一起预先拉起，召唤时直接唤醒已有实例——第三方应用首次冷启动通常要 1–3 秒，常驻能把这段省掉。

CC Switch 路径

可选外部工具，请选择本机安装路径；左侧 CC Switch 按钮用于启动它。

界面主题

系统内置两套背景参数，随时切换：深色 · 星夜 / 浅色 · 晨光。
