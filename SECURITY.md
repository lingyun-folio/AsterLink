# 安全问题

当前仅维护最新源码版本。星契会按用户配置启动本机程序，请只添加可信的启动目标，不要导入来源不明的配置。

不要在公开 Issue 中发布密钥、完整用户配置或可直接利用的安全细节。仓库建立后，请维护者在 GitHub 设置中启用 Private vulnerability reporting；启用后可通过 Security 页面的 Report a vulnerability 私下报告。

在该功能启用前，请勿在公开 Issue 贴出漏洞细节，可先提出不包含细节的联系请求。不要假定当前已经存在私有报告通道。

维护者发布修复后，将在版本说明中记录受影响范围和升级建议。本项目不承诺固定响应时限。

## English

Only the latest source version is maintained. Add trusted launch targets only. Do not disclose secrets or exploitable details in public issues. Once a GitHub repository exists, maintainers should enable private vulnerability reporting; this document does not claim that a private reporting channel is already available. Until then, request contact without disclosing exploit details. Fixes and upgrade guidance will be documented in release notes.
