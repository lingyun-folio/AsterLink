# 开发路线

以下是建议与已知问题，不是承诺的交付时间表。

## 优先修复

- 统一处理启动路径首尾引号，改进快捷方式参数解析。
- 校验配置和 IPC 入参，改用原子写入，明确提示保存与备份失败。
- 增加合适的内容安全策略和启动目标约束。

## 体验与兼容性

- 完整演出和快速召唤可选，衡量用户点击到目标可用的实际等待。
- 改进基于 exe 名称的运行检测，区分启动中、运行中与失败。
- 完善多显示器、小窗位置恢复、目标应用单实例差异的验证。
- 搜索、快捷键、键盘导航与减少动态效果。

## 个性化与长期探索

- 可导入的角色包及来源许可说明、配置导入导出。
- 应用适配层、工作区工具组合和最近使用。
- 评估 macOS / Linux，需要替换 Windows 专属系统集成。
- 模型调用与 Agent 编排属于独立扩展，需要另外设计权限和凭据管理。

## 已完成

- 星契 AsterLink 品牌与小灵狐应用图标。
- 公开版资源清理、默认个人路径清除、中英文文档和 MIT 许可。
- 源码资源检查、配置持久化回归与 Windows CI 配置。
